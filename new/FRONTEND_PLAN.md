# 王者用户端维护说明

## 数据边界

- 余额、房间、彩种、期号、开奖、注单、聊天、通知、活动和钱包流水全部以后端 API 与 WebSocket 为准。
- 接口异常时展示加载、失败或重试状态，不使用浏览器本地数据伪造业务结果。
- 浏览器只保存主题、字体、声音、头像等个人显示偏好，以及用于恢复登录体验的会话信息。
- 捕鱼、体育、真人、电子和电竞在供应商接口完成前只显示未开放状态，不生成虚假跳转地址。

## 交互与一致性

- 切换房间或彩种后清理上一会话的消息、注单、开奖助手回执和开奖状态。
- 聊天、通知和历史记录按服务端 ID 与时间排序，进入会话默认定位最新消息，历史数据使用游标加载。
- 投注只提交唯一请求 ID；实际期号、赔率、扣分、结算和余额由后端事务决定。
- WebSocket 是实时更新主通道；仅在连接中断时启用有限频率的补偿查询。

## 发布前检查

1. `npm run lint`
2. `npm test -- --run`
3. `npm run build`
4. 使用桌面端与手机完成登录、入房、下注、开奖、消息、钱包和个人设置回归。
