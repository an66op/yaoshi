# 七星票号：纯前端下一阶段开发计划

## 目标与边界

持续完成可交互、高保真、可演示的前端，不接真实账户、支付、开奖或投注接口。所有余额、期号、聊天、订单与通知均使用明确标注的模拟数据。

## 阶段 1：交互闭环与状态统一

- 将积分、签到、兑换、未读消息、优惠券、奖励收集到统一的前端状态层，并使用 `localStorage` 做本地持久化。
- 所有可点击入口都应有结果：加载态、成功反馈、空状态、已完成状态和可撤销操作。
- 统一消息已读规则：打开会话、查看通知、点击全部已读都会同步列表红点、底栏角标和通知数量。
- 建立演示数据重置入口，便于每次展示回到初始状态。

## 阶段 2：彩种互动页完善

- 拆分玩法配置：号码、多选组合、大小单双、冠亚、龙虎、金额与倍数。
- 增加下注草稿、注单卡片、撤回/复制、开奖记录详情与最近期号趋势。
- 完成开奖倒计时、封盘、开奖结果、中奖/未中奖消息的模拟状态机。
- 使用已选择的「彩票开奖通知」铃声在模拟开奖时播放，并提供静音开关。

## 阶段 3：消息、通知与客服

- 聊天按「会话 / 系统通知 / 活动通知 / 客服」拆分数据模型和阅读状态。
- 补充消息时间线、撤回、未读分割线、下拉加载历史、回到底部按钮。
- 客服加入可编辑输入框、发送、常用问题、自动回复与服务评价的演示流程。
- 将声音设置真正接入消息、红包、开奖和公告事件；支持全局静音和单类关闭。

## 阶段 4：个人中心与商城

- 个人中心补齐积分流水、奖励仓库、优惠券状态、注单筛选、账户安全与主题设置。
- 商城加入库存、兑换记录、已售罄、兑换确认、失败原因与奖励发放动画。
- 让大厅余额、商城积分、个人中心流水和奖励仓库共享同一套模拟状态。

## 阶段 5：体验、适配与交付质量

- 覆盖 320 / 375 / 390 / 430 宽度以及短屏、横屏、PC 预览；消除双滚动条与底栏遮挡。
- 完成日间/夜间两套颜色令牌，避免跨页面样式覆盖；支持系统主题跟随。
- 增加骨架屏、空状态、错误状态、减弱动画选项、键盘操作与 `aria` 标签。
- 拆分大样式文件为组件级样式，压缩音频与图片资源，完成构建、lint 和路由直达校验。

## 建议顺序

先做阶段 1 和阶段 2：它们会让大厅、彩种互动页、底栏未读数、商城和个人中心共享同一份演示数据，后续页面不再是彼此独立的壳子。
