# 开奖助手下单规则

本文记录开奖助手当前支持的文本下单格式、金额计算、解析结果与使用限制。

## 一、基本格式

```text
玩法/金额#玩法/金额#玩法/金额
```

1. `/` 用于分隔名次、投注内容和金额。
2. `#` 用于分隔多组投注。
3. 开头可以加“买”，也可以不加。
4. 不需要逗号。
5. 任意一组格式错误，整张订单都会拒绝，不会部分扣分。
6. 整张订单一次扣除总金额并生成全部注单。

## 二、指定名次购买多个号码

格式：

```text
名次/号码组合/该组总金额
```

示例：

```text
1/12345/100
```

解析：

1. 第1名购买号码1，金额20。
2. 第1名购买号码2，金额20。
3. 第1名购买号码3，金额20。
4. 第1名购买号码4，金额20。
5. 第1名购买号码5，金额20。
6. 共5注，总金额100。

最后的100是这一组的总金额，因此5个号码平均分配，每个号码20。

再例如：

```text
7/67890/100
```

在赛车、飞艇、幸运10中，号码 `0` 代表号码10。

解析：

1. 第7名购买号码6，金额20。
2. 第7名购买号码7，金额20。
3. 第7名购买号码8，金额20。
4. 第7名购买号码9，金额20。
5. 第7名购买号码10，金额20。
6. 共5注，总金额100。

如果需要每个号码购买100，应输入：

```text
1/12345/500
```

因为5个号码 × 100 = 总金额500。

## 三、指定名次购买大小单双

支持两种写法：

```text
6/大/200
6大/200
```

两种写法含义相同：第6名购买“大”，共1注，金额200。

其他示例：

```text
1/小/100
3/单/500
5/双/200
8/大/100
10/单/50
```

赛车、飞艇、幸运10的大小规则：

1. 号码1～5为“小”。
2. 号码6～10为“大”。
3. 奇数为“单”。
4. 偶数为“双”。

## 四、同时购买多个名次

多组投注使用 `#` 分隔。

示例：

```text
1/12345/100#6/大/200#7/67890/100
```

解析：

1. 第1名购买1、2、3、4、5，共5注，每注20，合计100。
2. 第6名购买“大”，共1注，金额200。
3. 第7名购买6、7、8、9、10，共5注，每注20，合计100。
4. 整张订单共11注，总金额400。

如果需要第1名和第7名的每个号码都购买100，应输入：

```text
1/12345/500#6/大/200#7/67890/500
```

解析：第1名合计500，第6名合计200，第7名合计500，整张订单总金额1200。

同一条消息可以继续增加更多名次：

```text
1/12345/100#4/大/200#5/单/100#6/小/200#7/67890/100#9/双/300
```

## 五、使用中文名次

支持以下名次：

1. 冠军
2. 亚军
3. 第三名
4. 第四名
5. 第五名
6. 第六名
7. 第七名
8. 第八名
9. 第九名
10. 第十名

示例：

```text
冠军/大/100
冠军大/100
亚军/单/200
第七名/8/100
第十名/0/100
```

解析：

1. `冠军/大/100`：冠军购买“大”，金额100。
2. `冠军大/100`：与上一条含义相同。
3. `亚军/单/200`：亚军购买“单”，金额200。
4. `第七名/8/100`：第7名购买号码8，金额100。
5. `第十名/0/100`：在赛车类游戏中，第10名购买号码10，金额100。

购买多个号码时，建议使用数字名次写法：

```text
7/12345/500
```

## 六、按顺序购买号码

格式：

```text
连续号码/金额
```

示例：

```text
12345/1000
```

解析：

1. 第1名购买号码1，金额200。
2. 第2名购买号码2，金额200。
3. 第3名购买号码3，金额200。
4. 第4名购买号码4，金额200。
5. 第5名购买号码5，金额200。
6. 共5注，总金额1000。

开头可以加“买”：

```text
买12345/1000
```

涉及第6～10名时，建议使用明确名次写法，避免和顺序号码混淆：

```text
6/12345/500#7/67890/500
```

## 七、单个号码或单个两面

没有填写名次时，默认购买第1名。

示例：

```text
5/100
大/100
小/100
单/100
双/100
龙/100
虎/100
```

解析：

1. `5/100`：第1名购买号码5，金额100。
2. `大/100`：第1名购买“大”，金额100。
3. `单/100`：第1名购买“单”，金额100。

为了避免歧义，建议明确填写名次，例如：

```text
1/大/100
```

## 八、冠亚和

当前支持：

```text
冠亚和大/200
冠亚和/大/200
冠亚和小/200
冠亚和/单/100
冠亚和/双/100
```

每一组都是单注，末尾金额就是该注金额。

解析示例：

```text
冠亚和/大/200
```

解析：冠亚和购买“大”，共1注，金额200。

## 九、龙虎

当前支持：

```text
冠军龙/100
冠军虎/100
冠军/龙/100
1/虎/100
```

解析示例：

```text
冠军/龙/100
```

解析：冠军购买“龙”，共1注，金额100。

## 十、形态玩法

当前支持：

```text
豹子/50
顺子/50
对子/50
半顺/50
杂六/50
```

形态玩法按照前3个开奖号码判断，每组都是单注，末尾金额就是该注金额。

示例：

```text
豹子/50#对子/100
```

解析：豹子1注50，对子1注100，整张订单总金额150。

## 十一、金额计算规则

1. 最后一个 `/` 后面的数字是当前组的总金额。
2. 单个选择使用该组全部金额。
3. 一组包含多个号码时，总金额平均分配到每个号码。
4. 多组投注的金额相加后一次扣除。
5. 相同名次、相同号码和相同玩法重复出现时，会合并金额。
6. 金额必须大于0，可以使用小数，最终精确到分。

单个选择示例：

```text
6/大/200
```

解析：1注，金额200。

多个选择示例：

```text
1/12345/100
```

解析：5注，总金额100，每注20。

金额无法整除时会精确分配：

```text
1/123/100
```

解析：

1. 号码1分配33.34。
2. 号码2分配33.33。
3. 号码3分配33.33。
4. 合计100.00。

## 十二、游戏与名次限制

1. 赛车、飞艇、幸运10支持第1～10名。
2. 时时彩、幸运5等通常使用第1～5名。
3. 实际可用名次以该彩种的开奖号码数量为准。
4. 赛车、飞艇、幸运10中，输入号码 `0` 代表号码10。
5. 彩种停用、封盘、开奖源异常或期号切换时不能提交。
6. 提交时会检查余额、单注限额和单期限额。

## 十三、整单提交规则

1. 所有分组先完成解析和校验。
2. 校验通过后统一扣除整张订单金额。
3. 所有注单在同一个事务内创建。
4. 任意一组格式错误、余额不足或超过限额时，整张订单不提交。
5. 连点或网络重试使用请求编号防止重复扣分。
6. 成功订单会保存到开奖助手历史和用户注单中，刷新后仍可查看。

## 十四、不支持的格式

以下写法不支持：

```text
1,2,3/100
1，2，3/100
1/12345
1/12345/100元
1／12345／100
1/12345/100＃6/大/200
```

必须使用英文半角 `/` 和 `#`：

```text
1/12345/100#6/大/200
```

## 十五、标准完整示例

```text
1/12345/100#6/大/200#7/67890/100
```

最终解析：

1. 第1名5注，合计100。
2. 第6名1注，合计200。
3. 第7名5注，合计100。
4. 整张订单共11注，总金额400。
