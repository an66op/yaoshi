# 规则解析

> 金额均为当前这一组的总金额；多组投注使用半角 `#` 分隔，不使用逗号。

## 1. 指定名次购买多个号码

格式：`名次/号码/金额`

示例：`1/12345/100`

解析：第1名购买1、2、3、4、5，共5注；总金额100，每注20。

## 2. 指定名次购买大小单双

格式：`名次/玩法/金额`

示例：`6/大/200`

解析：第6名购买“大”，共1注，金额200。

同样支持：`1/小/100`、`3/单/200`、`5/双/100`。

## 3. 同时购买多个名次

格式：每组之间使用 `#` 分隔。

示例：`1/12345/100#6/大/200#7/67890/100`

解析：

1. 第1名购买1、2、3、4、5，共5注，每注20，合计100。
2. 第6名购买“大”，共1注，金额200。
3. 第7名购买6、7、8、9、10，共5注，每注20，合计100。
4. 整张订单共11注，总金额400。

赛车、飞艇和幸运10中，号码 `0` 代表号码10。

## 4. 使用中文名次

支持：冠军、亚军、第三名、第四名、第五名、第六名、第七名、第八名、第九名、第十名。

示例：`冠军/大/100#第七名/8/200`

解析：冠军购买“大”100；第七名购买号码8，金额200。

也支持省略中间斜杠：`冠军大/100`、`第七名8/200`。

## 5. 按顺序购买号码

格式：`连续号码/金额`

示例：`12345/1000`

解析：第1名买1、第2名买2、第3名买3、第4名买4、第5名买5；共5注，总金额1000，每注200。

开头可以加“买”：`买12345/1000`。

## 6. 默认购买第1名

示例：`5/100`、`大/100`、`单/100`。

解析：没有填写名次时，默认购买第1名；末尾金额就是该注金额。

## 7. 冠亚和

示例：`冠亚和/大/200`、`冠亚和小/100`、`冠亚和/单/100`、`冠亚和双/100`。

解析：购买冠亚和对应的大小或单双，每组1注，末尾金额为该注金额。

## 8. 龙虎

示例：`冠军/龙/100`、`1/虎/100`。

解析：购买冠军龙虎，每组1注，末尾金额为该注金额。

## 9. 形态玩法

支持：`豹子/金额`、`顺子/金额`、`对子/金额`、`半顺/金额`、`杂六/金额`。

示例：`豹子/50#对子/100`

解析：豹子1注50，对子1注100；总金额150。

## 10. 金额与提交规则

1. 最后一个 `/` 后面的数字是当前组的总金额。
2. 一组有多个号码时，总金额平均分配到每个号码。
3. 金额无法整除时按分精确分配，例如 `1/123/100` 为33.34、33.33、33.33。
4. 所有分组金额相加后一次扣除。
5. 任意一组格式错误、余额不足、超过限额或已经封盘时，整张订单不提交。
6. 赛车、飞艇、幸运10支持第1至第10名；其他彩种按实际开奖号码位置使用。
7. 必须使用半角 `/` 和 `#`，不支持逗号、金额单位或全角符号。

## 当前标准示例

```text
1/12345/100#6/大/200#7/67890/100
```

解析结果：第1名5注100 + 第6名1注200 + 第7名5注100 = 共11注，总金额400。
