# 代理 · 房间靓号 · 开奖接口

> 更新时间：2026-08-22

## 1. 产品语义

| 概念 | 含义 |
|------|------|
| **靓号** | = **代理房间号**（不是会员账号昵称） |
| **代理** | 购买/获发靓号后，用该号作为自己的房间入口 |
| **用户进房** | 输入房间号 → 解析到对应代理 → 进入该代理房间 |
| **系统设置 room_code** | 平台总房间/默认展示号，与代理靓号分开 |

### 后台入口

- **代理管理** `/agents`：代理列表、分配房间号
- **房间靓号** `/special-numbers`：号码池、活动、发放（发放自动升代理）
- **申请管理**：代理申请审核通过后自动 `role=agent`（仍需再分配房间号）

### 关键 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/public/rooms/:code` | 用户端校验房间号，返回代理信息 |
| GET | `/api/admin/agents` | 代理列表 |
| POST | `/api/admin/agents/:id/promote` | 升为代理（可带 room_code） |
| POST | `/api/admin/special-numbers/assign` | 直接把可用号码分给用户并升代理 |
| POST | `/api/admin/special-numbers/grant` | 活动发放（同样升代理+绑房间号） |

## 3. 还有哪些「能找到接口」、可后续接入

> 说明：下面多为**第三方开奖聚合站**（非各国官方站）。接入前需自行评估稳定性、合规与费用；本仓库目前**未内置**这些第三方密钥对接。

### 与本系统模拟盘高度重合（优先候选）

| 本系统彩种 | 常见第三方可覆盖 |
|------------|------------------|
| 澳洲幸运10 / 澳洲幸运5 | 168 类、开奖网 API 等 |
| 幸运飞艇 / 极速飞艇 / SG飞艇 | 同上高频 PK10/飞艇类 |
| 极速赛车 / 极速时时彩 | 同上 |
| 香港六合彩 | 六合聚合接口常见覆盖 |
| 新澳门 / 老澳门六合 | 部分开奖网有「澳门/新澳门」 |
| 台湾宾果 | 已有官方源；第三方也常有镜像 |

### 目标清单里较难「官方直连」的

| 彩种 | 说明 |
|------|------|
| 宾果时时彩一~四、宾果赛车 A/B、宾果六合 | 多为盘口自编玩法，通常**映射**台湾宾果/自建期号，少有独立官方 API |
| 快乐8六合彩 | 玩法包装，≠ 福彩快乐8；需自建规则或第三方定制源 |

### 参考站点（调研用，非已集成）

- 168/聚合类：文档常列 PK10、时时彩、六合（港/澳）等高频
- 商业开奖 API 租用站：按彩种月费租 token
- 各国官方：福彩/体彩/台湾彩券（本系统已用）；港彩/澳彩官方页面抓取需单独评估反爬与稳定性

### 建议接入顺序

1. **澳洲幸运10 / 幸运飞艇 / 极速系列**（与现有模拟盘一一对应，第三方源多）  
2. **香港六合、新/老澳门六合**（目标清单刚补齐）  
3. **宾果系列** → 优先映射已接的 `official-tw-bingo`，或统一第三方宾果源再拆房
