# 开奖助手下单规则

完整且唯一维护的规则说明见 [规则解析](规则解析.md)，纯文本快捷参考见 [规则解析.txt](规则解析.txt)。

## 核心约定

末尾 `/` 后是每个具体投注项的单注金额。未写名次时，所有号码都属于冠军，不按先后分配名次。

| 输入 | 展开项数 | 总扣款 |
| --- | ---: | ---: |
| `1/12345/100` | 5 | 500 |
| `489/0178/48` | 12 | 576 |
| `5/045/343` | 3 | 1029 |
| `68/单大/811` | 4 | 3244 |
| `62437/546` | 5 | 2730 |
| `1/12345/100#6/大/200#7/67890/100` | 11 | 1200 |

相同名次、玩法和号码重复出现时会合并金额；例如 `4444/88` 保存为冠军号码4金额352。赛车号码组合中的 `0` 代表10。

## 实现与验证

- 后端解析：`backend/services/assistant_bet.go`。
- 前端预览：`new/src/utils/betParser.ts`。

- 实际下单以服务端的期号、金额、余额、玩法及限额校验为准，整单事务提交。
